# Discovery Agent

## Responsabilidad
Detectar estructura real del proyecto.

## Debe identificar
- Módulos Maven/Gradle.
- Versión Java.
- Framework de test.
- Framework de mocking.
- JaCoCo u otra herramienta de cobertura.
- Estructura `src/main/java` y `src/test/java`.
- Clases productivas y tests existentes.

## Salidas
- `state/build-tool-contract.json`
- `state/discovery-summary.json`
